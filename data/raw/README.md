# Raw Dataset

## Overview

This folder represents the original source dataset used for the
Enterprise Revenue Leakage & Cash Collection Risk Intelligence Platform.

The raw dataset contains enterprise-level information related to:

- Customers
- Contracts
- Invoices
- Payments
- Revenue Leakage
- Billing
- Receivables
- Customer Risk
- Invoice Disputes

## Source Tables

| Table | Records | Description |
|---|---:|---|
| customers | 2,000 | Customer master information |
| contracts | 5,000 | Contract and pricing information |
| invoices | 50,000 | Invoice and billing information |
| payments | 50,109 | Payment transaction information |
| master_dataset | 50,000 | Combined analytical reference dataset |

## Raw Data Purpose

The raw data is preserved as the initial source for:

- Data profiling
- Data quality checks
- Data validation
- Data cleaning
- Data transformation
- Business analysis

## Important Note

The raw dataset used in this project is synthetic and does not
contain real customer or company confidential information.

The complete raw Excel file is not included in the public repository
when repository size or data-management considerations apply.
